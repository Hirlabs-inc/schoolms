You are a senior QA engineer. Your task is to do a FULL comprehensive testing of this school management system.

## Project Overview
- **Name**: Trainify School Management System
- **Tech Stack**: Next.js 16 (App Router), TypeScript, Tailwind v4, Radix UI, Supabase, React Hook Form + Zod, Vitest + jsdom
- **Core Modules**: Auth (login/logout/password reset), User Management (Admin creates students/teachers), Classes (Grade 1-12), Courses (per class), Exams & Results, Attendance (with SMS notifications), Student Promotion, Fees/Payments, Payroll, Income/Expenses, Enrollment Progress
- **Roles**: ADMIN (full access), TEACHER (manages courses/exams/attendance for assigned classes), STUDENT (read-only access to own records)
- **Database**: Supabase PostgreSQL with RLS policies

## What already exists
- 1 test file: `lib/__tests__/api.test.ts` (~42 tests) covering auth, CRUD, createUser, payroll, income, enrollment, edge cases, security
- Vitest setup with in-memory mock DB in `vitest.setup.ts`
- Run existing tests with: `npx vitest run`
